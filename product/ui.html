Installation health
Installation is an admin action. It downloads project dependencies and browsers; Node.js/npm must already be installed. No source update is installed automatically.
ComponentAvailableDetails / recovery
For product updates, stop the app, back up product-data, extract the reviewed new release and point --data-dir at the retained folder. Keep Python requirements current through the supplied installer.


Accounts & project access
Admin manages accounts. Tester can run/edit accessible projects. Viewer can inspect sanitized text reports. This server listens on your computer only.
Private inputs
Values are stored in your OS credential store, not the workflow JSON. There is no browser endpoint to read them back. Project testers can use them in approved workflows.
Retention
Admin only. Run metadata and review audit records are retained. Keep the product-data folder private; raw evidence can contain credentials.
